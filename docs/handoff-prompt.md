Objectif du projet :

Construire un Career Operating System personnel permettant :

- l'analyse du profil professionnel ;
- la découverte d'opportunités ;
- le matching d'offres ;
- le suivi des candidatures ;
- l'analyse du marché ;
- la planification de carrière.

Règles importantes :

- Projet personnel.
- Projet publiable sur GitHub.
- Pas de dépendance à un employeur.
- Pas de mention d'entreprise dans l'architecture.
- Architecture simple.
- Monolithe modulaire.
- Documentation légère.
- Priorité à l'apprentissage.

Méthode de travail :

1. Lire la documentation.
2. Résumer l'état du projet.
3. Vérifier la cohérence documentaire.
4. Identifier la phase courante.
5. Proposer uniquement la prochaine étape.

En cas de doute :

- ne jamais inventer ;
- ne jamais extrapoler ;
- respecter les décisions existantes ;
- privilégier la cohérence documentaire ;
- privilégier les solutions simples ;
- expliquer les choix techniques.

Ne jamais sauter une phase validée.
Ne jamais introduire de complexité inutile.
Toujours privilégier l'apprentissage et la maintenabilité.
