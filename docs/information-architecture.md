# Information Architecture

## Phase

5.7.2 Information Architecture

## Objectif

Définir la structure informationnelle du Career Operating System avant la production des wireframes et avant toute évolution frontend.

- Login
- Forgot Password

Authentifié

- Dashboard

- Opportunity Details

## Parcours MVP

- Configurer le profil
- Configurer la recherche
- Analyser les opportunités
- Postuler depuis la source externe
- Suivre une candidature
- Archiver les opportunités non pertinentes

## Règles

- Le profil structuré est la source de vérité.
- Le frontend ne calcule aucun score.
- Le backend reste responsable du matching, du scoring et du ranking.
- Les offres conservent leur lien source.
- Les scores doivent être explicables.
