# Career Operating System

Career Operating System is a personal platform designed to help manage and improve a professional career using data, AI and market insights.

## Goals

- Understand current market positioning
- Discover relevant opportunities
- Analyze career gaps
- Prepare applications
- Track career progression
- Learn modern software architecture

## Core Modules

- Candidate Intelligence
- Opportunity Discovery
- Matching Engine
- Application Assistant
- Market Intelligence
- Career Roadmap

## Technology Stack

Frontend:

- React
- TypeScript
- Vite

Backend:

- Python
- FastAPI

Database:

- PostgreSQL

AI:

- OpenAI API
